# RoleVow

**Play your role, now it's your roll. Our vow? To make you say wow.**

> **Status: Pre-release.** RoleVow is not yet ready for public use.

RoleVow is the planned English-language edition of [Divertoscopio](https://github.com/massimilianobanini/divertoscopio), an open-source, AI-assisted tool for tabletop role-playing games (TTRPGs).

The goal is to make it easier to start playing, prepare sessions, and continue adventures with existing tabletop RPG systems. RoleVow is not a new standalone ruleset and does not replace the choices of players or Game Masters.

## Development and release status

- **Primary development:** Divertoscopio (Italian).
- **International edition:** RoleVow (English first; additional languages may follow).
- **Updates:** Changes are adapted from verified Divertoscopio releases, then reviewed and tested separately in English.
- **Release safeguards:** Privacy, secrets, licensing, technical integrity, gameplay, and public claims must pass pre-publication review.

**The English-language product and its Negative-Price Ultra-Guarantee are not yet available.** This repository does not currently offer compensation or guarantee any gameplay outcome.

For the existing Italian project, see [Divertoscopio](https://github.com/massimilianobanini/divertoscopio).
