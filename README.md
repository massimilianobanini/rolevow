# RoleVow

**The first Simple Tabletop RPG Tool, with the Negative Price Ultra-Guarantee.**

**Play your role, now it's your roll. Our vow? To make you say wow.**

> **Status: Pre-release — RC-EN-0.9 public technical playtest.** The source is available for controlled tests; it is not yet ready for public use as a validated product.

RoleVow is the English-language edition of [Divertoscopio](https://github.com/massimilianobanini/divertoscopio), an AI-assisted tool for existing tabletop RPGs, not a new ruleset. No independent English human actual-play results are claimed.

## Start a test

Open a new ChatGPT conversation and paste:

```text
https://github.com/massimilianobanini/rolevow

Let's begin.
```

If the repository cannot be read, open [BOOTSTRAP.md](BOOTSTRAP.md) and supply its text; do not treat a fallback as full validation. Select Player or Game Master. D&D 2014/SRD 5.1, D&D 2024/SRD 5.2.1, and the Daggerheart™ unofficial experimental adapter are included for evaluation. The latter was refined based on player feedback documented in Divertoscopio, not independent RoleVow English validation. Hosted groups use one human host and one chat; no separate private player channels.
