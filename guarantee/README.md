Parameters (not a public offer): 100 cents net, 2000 cents monthly gross, 10000 cents lifetime gross including binding commitments. One payment per person across the two brands, first-in-first-out review, only lawful verified routes, no automatic payout. A positive result means only that a synthetic input passed this model. From the repository root run `python -m unittest discover -s tests -p "test_*.py" -v`. No personal data or external services are necessary. The live backend is separate from this sandbox; actual payout and cross-brand checks remain manual.
